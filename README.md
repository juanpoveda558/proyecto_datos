# Weather Data Analysis Dashboard 🌦️

Este proyecto procesa datos climáticos almacenados en archivos CSV para generar visualizaciones métricas utilizando Python.

## 📊 Datos Procesados
El script analiza las siguientes variables:
* Temperatura, Humedad, Presión Atmosférica y Velocidad del Viento.

## 🛠️ Tecnologías
* **Python 3.x**
* **Pandas**: Para la manipulación de estructuras de datos.
* **Matplotlib/Seaborn**: (Próximamente) Para la generación de gráficos.

## 🚀 Instalación y Uso
1. Clonar el repositorio.
2. Asegurarse de tener instalado pandas: `pip install pandas`.
3. Ejecutar el script principal: `python main.py`.
